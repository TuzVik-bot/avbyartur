# Подключение OpenRouter

Провайдер выбран пользователем: OpenRouter, строго бесплатные модели. Рекомендуемый начальный ID из актуального каталога 14 октября 2026: `google/gemma-4-31b-it:free`. API-каталог подтверждает нулевые цены входа/выхода и поддержку `response_format`. Качество русскоязычного подбора необходимо проверить с установленным ключом.

## Ключ

Создайте отдельный ключ в https://openrouter.ai/settings/keys. Ограничьте доступ этим проектом. Приложение отклоняет модели без `:free` и провайдеры вне `openrouter.ai`, не использует платные fallback. OpenRouter применяет собственные ограничения бесплатных запросов; тариф аккаунта не гарантирует безлимитный бесплатный API.

После деплоя запустите в локальном терминале:

```sh
python3 /Users/home/Downloads/avbyartur/scripts/configure-assistant-openrouter.py
```

Ключ вводится через getpass, передаётся stdin по SSH и сохраняется только в VPS `.env` mode600. Скрипт пересоздаёт только web без сборки; образ должен быть уже подготовлен. Не вводите ключ в чат, не передавайте как аргумент команды.

## Лимиты и приватность

- До 20 обращений за 5 минут на IP, 200 в час на экземпляр и 3 одновременных. Счётчики сбрасываются при перезапуске; это ограничения нагрузки, а не финансовый бюджет.
- Запрос до 20 KB, сообщение до 1200 символов, история до 6 сообщений, текст публичной страницы до 6000 символов. Ключ доступен только серверу.
- OpenRouter получает текст сообщения/ограниченную историю, фильтры, справочный каталог и текст публичной страницы при пересказе. Cookies, кабинет, формы, пароли и телефоны сервер не передаёт.
- `data_collection=deny`, без fallback провайдера. Если у выбранной бесплатной модели нет подходящего endpoint, будет явная ошибка; платный маршрут не включается.
- Чат хранится в памяти открытой страницы, не сохраняется в БД или localStorage. Пользователь может сбросить разговор. Серверный код не логирует тело запросов и ключи.
- Озвучивание использует браузерный speechSynthesis. Распознавание SpeechRecognition может использовать сервис браузера; запускается только кнопкой микрофона с разрешением пользователя. При отсутствии поддержки используется текстовый ввод.

Статус подключения: GET `/api/assistant`, `engine=ai` означает наличие конфигурации, но успешный вызов модели подтверждается отдельной проверкой POST. При отсутствии ключа `engine=basic` честно показывает ограниченный поиск и краткий текстовый пересказ.
