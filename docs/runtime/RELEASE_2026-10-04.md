## Текущая предпосылка для следующего релиза

При последней read-only проверке действующий VPS-релиз `pilot-20261004T123401Z` всё ещё обслуживался без HTTP Basic Auth; `noindex` был включён, API и PostgreSQL напрямую не опубликованы.
