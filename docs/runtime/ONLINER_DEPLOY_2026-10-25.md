## Синхронизация

В общем `.env` (600) задано `ONLINER_SYNC_ENABLED=true`,
`ONLINER_SYNC_OWNER_EMAIL=mirror-onliner@avtorinok.local`,
`ONLINER_SYNC_INTERVAL_HOURS=6` (по умолчанию), `ONLINER_SYNC_MANUFACTURERS=all`;
worker перезапущен. Джоба обновляет цены, ставит на паузу закрытые и
возвращает переоткрытые, затем импортирует новые объявления по маркам.
Отключение зеркала: `ONLINER_SYNC_ENABLED=false` + снятие импортированных
объявлений (slug вида `onliner-<id>`).

  синхронизация из worker-контейнера окажется слишком медленной, перенести
  её на host-cron с тем же CLI (`sync`).
