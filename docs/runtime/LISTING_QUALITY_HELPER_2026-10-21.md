# Помощник качества объявления — 21 октября 2026

На последнем шаге формы `/sell` показан checklist перед отправкой, отдельные необязательные рекомендации для автомобильного объявления и подсказки к фотографиям по категории.

## Как работает

- Список обязательных характеристик транспорта берётся из уже загружаемого формой `listing-validation-policy`; общие проверки совпадают с текущими проверками формы и отправки: состояние, описание, цена, расположение, телефон и минимум обработанных фотографий.
- Статус «Заполнено» означает только наличие данных в текущей форме. Это не отметка модератора и не подтверждение достоверности сведений.
- Незаполненное поле, которое есть в форме, имеет кнопку для перехода к шагу и фокусировки нужного контрола. Автосохранение черновика и обработка фотографий остаются прежними.
- VIN, объём и мощность двигателя показаны только как необязательные подсказки для легковых автомобилей. Они не меняют правила публикации.
- Фотоподсказки перечисляют полезные ракурсы и детали. Помощник не проверяет по ним наличие или подлинность фотографий.
- Обязательные `category_details` для иных категорий перечисляются по политике как «Не проверено»: текущая форма не предоставляет для них контролов. Статус checklist не выключает кнопку отправки и не добавляет локальную валидацию.
- Для нового объявления используется текущая серверная категория по умолчанию — `cars`. Для существующего объявления категория читается из ответа API, если она присутствует.
- Для проверки контакта помощнику передаётся только признак заполненности, не сам номер. Внешние AI-вызовы не используются.

Код находится в [listing-quality.ts](../../web/src/lib/listing-quality.ts) и [sell-form.tsx](../../web/src/components/sell-form.tsx). Помощник отображается в существующем предпросмотре, дубликат предпросмотра не создаётся.
