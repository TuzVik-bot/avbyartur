# История цены и уведомления о снижении

Дата проверки: 21 октября 2026 года.

## Поведение

- История фиксирует цену в исходной валюте при публикации и при каждом одобренном изменении публичной цены.
- Для уже активного объявления без истории baseline записывается лениво: перед первым редактированием продавцом или обновлением из dealer feed. В baseline попадает старая опубликованная цена; это событие не создаёт уведомления.
- Изменение продавца или дилерского feed переводит объявление в черновик. Новое состояние цены попадает в историю после повторного одобрения модератором.
- Уведомление создаётся только для снижения суммы в той же валюте и только для пользователя, который включил опцию у объявления в избранном. Владелец объявления исключён. Перед доставкой worker повторно проверяет избранное, подписку, активность получателя и публичную доступность объявления.
- При паузе и повторном включении объявления без изменения цены дублирующее событие не создаётся.

## API и интерфейс

- `GET /api/v1/listings/{listing_id}/price-history` возвращает публичную историю активного объявления.
- `PUT /api/v1/me/favorites/{listing_id}/price-drop-alert` принимает `{ "enabled": boolean }` и требует CSRF.
- Страница объявления показывает историю с исходными суммами и валютами. Избранное содержит отдельное управление opt-in и ссылку на настройки уведомлений.
- Для legacy-объявлений интерфейс обозначает baseline как «Цена зафиксирована», без ложного предыдущего значения.

## Хранение

Alembic revision `0025_listing_price_hist` добавляет `listing_price_events`, opt-in в `favorites` и связь событий с outbox/inbox. Ограничение `ck_listing_price_event_type` разрешает `baseline`, `published`, `added`, `changed` и `removed`. Миграция не делает массовую начальную запись активных объявлений.

## Проверки

- Backend: 10 целевых интеграционных тестов прошли: весь `test_price_history_notifications.py` и dealer-feed regression для legacy active listing. Регрессии проверяют seller edit → baseline → одобрение → снижение; а также feed update → baseline до демоции → одобрение → одно уведомление opted-in получателю.
- Миграция: отдельная пустая disposable `_test` БД прошла один `alembic upgrade head` до `0025_listing_price_hist`. В эту БД успешно записано событие `baseline`; применённый check constraint содержит `baseline`.
- Frontend: тест страницы объявления после добавления baseline label прошёл, 19 тестов; `corepack pnpm typecheck` прошёл.
- OpenAPI-типы пересозданы командой `corepack pnpm generate:api-types`; в сгенерированном union есть `baseline`. `git diff --check` по изменённым backend и generated-type файлам прошёл.

## Выпуск

Изменения проверены локально. Push и deploy не выполнялись; реальное production-поведение и браузерный сценарий на активном одобренном объявлении не подтверждались.
