# Приемка canonical домена `авторынок.бел` — 21 октября 2026

## Область

Пользователь уточнил, что рабочий домен проекта — `https://авторынок.бел`.
Браузер нормализовал точное имя домена в IDNA-форму
`xn--80aeylebmo7f.xn--90ais`. Предыдущий TLS-диагноз относится только к
устаревшему `suite-s1.denjik.by` и не является инцидентом доступности
`авторынок.бел`.

Проверки ниже выполнялись только чтением публичных страниц и API, без входа в
аккаунт и без создания тестовых объявлений.

## Публичный HTTPS и API

- HTTPS GET `/` завершился `200` с обычной проверкой сертификата. Ответ
  содержит `X-Robots-Tag: noindex, nofollow, noarchive`.
- HTTP GET `/` перенаправил `301` на HTTPS того же домена.
- `GET /api/v1/auth/capabilities` вернул `200` и сообщил:
  `email_registration=true`, `email_registration_pilot=true`,
  `email_verification=true`, `password_recovery=true`.
- `GET /api/v1/listings` вернул `200` и `items: []`.
- `GET /api/v1/listings/compare?ids=00000000-0000-0000-0000-000000000000`
  вернул `200` и `items: []`; запрос не создавал запись.
- Страницы `/registration-terms` и `/registration-privacy` вернули `200`.
  Их заголовки: «Условия тестовой регистрации — Авторынок BY» и «Данные при
  тестовой регистрации — Авторынок BY».

## Браузерная приемка

Проверка выполнена в in-app browser на canonical HTTPS-домене.

- `/login?next=%2Fsell` открылся без TLS-предупреждения. После загрузки
  capability-ответа появилась опция «Создать аккаунт».
- Выбор «Создать аккаунт» открыл поля имени, email, пароля и повтора пароля,
  обязательные согласия с условиями и политикой обработки данных, а также
  кнопку «Зарегистрироваться». Регистрация не отправлялась.
- Форма прямо сообщает, что реквизиты оператора пока не опубликованы и не
  следует размещать чувствительные данные. Успешная отдача страниц условий не
  означает юридическую проверку или публикацию недостающих реквизитов.
- `/cars` показывает `0` предложений и состояние пустой выдачи. Ссылки «Сохранить
  поиск» и «Подписаться на новые объявления» ведут на вход с `next=/cars`.
- `/dealers` показывает пустое состояние «Компании пока не добавлены».
- `/compare` показывает состояние «Пока нет объявлений для сравнения» и ссылку
  перехода в каталог. После обновления страницы пустое состояние сохранилось.

## Текущий runtime и ограничения приемки

Во время свежей read-only SSH-проверки alias `fortebit-prod` активная ссылка
`/home/suite/apps/avtorinok` указывала на
`/home/suite/apps/releases/listing-create-20261021-r1`. API, web, worker, DB и
test-mail были healthy. Фактический target `.env` имел режим `600`; содержимое
не читалось. Переключений релиза, изменений Nginx/TLS/DNS и других удалённых
изменений не выполнялось.

Публичный API не содержит активных объявлений. Поэтому сравнение реальных машин,
добавление/удаление элементов, ограничение до четырёх карточек и сравнительная
таблица недоступны для приемки без тестовых объявлений; новые записи на VPS не
создавались. Мобильное отображение сравнительной таблицы также не проверялось.

Старый результат TLS для `suite-s1.denjik.by` остаётся историческим фактом о
том hostname и не описывает доступность `https://авторынок.бел`.
