# Каталог грузовиков и мотоциклов: пакет 01

Запрос владельца: добавить грузовые модели и мотоциклы из
`autorinok_catalog_pack_01.zip` на сервер. Дата отчёта: 15 октября 2026, Минск.

## Результат

- Импортированы все 718 исходных моделей: 380 `motorcycles`, 338 `trucks`.
- 20 исходных марок: 17 новых, 3 существующих переиспользованы (BMW, Honda, Suzuki).
- Итого БД: 111 марок, 3348 моделей; без изменения количества поколений
  (14009), модификаций (194817) и объявлений (204).
- Это справочник моделей, не объявления о продаже. Состояние исходных записей
  `source_raw` сохранено. Возможные особенности классификации NHTSA не исправлялись
  предположениями. Годы, поколения, комплектации и характеристики не создавались.
- Сохранены исходные `brand_id`, `model_id`, URL, дата, исходные строки и SHA-256
  в `source_metadata.catalog_pack_01`. Существующие UUID, названия и источники
  переиспользованных марок сохранены; добавлена только метаинформация пакета.
- `category_codes` в метаданных обеспечивает отдельную выдачу категорий.
  Созданные пакетом строки исключены из каталога легковых автомобилей.
- В форме подачи грузовиков и мотоциклов добавлены подсказки марок/моделей
  через datalist; ручной ввод остаётся доступным. Подача сохраняет существующий
  контракт ручных значений, без создания синтетических объявлений.

SHA-256 ZIP: `ed6f16a880fd3ce54a934d16f7ef420c74b3ed5f8ca3dd131dfed27cc15ee873`.

## Изменения и воспроизводимость

- Локальный импортер: `scripts/import_catalog_pack_01.py`. Запускается в окружении
  приложения; без `--apply` выполняется откат всей транзакции. PostgreSQL advisory
  lock защищает от одновременного запуска этого импортера.
- Patch подключения относительно актуального серверного кода:
  `docs/runtime/catalog-pack-01-20261015.patch`.
- Исходный локальный checkout существенно изменён другими задачами. Его backend
  и web файлы не перезаписывались серверной версией; patch сохранён отдельно,
  чтобы будущий релиз мог явно включить интеграцию и не откатить её.
- Серверный рабочий каталог: `/home/suite/apps/catalog-pack-01-20261015`.
- API image: `avtorinok-api:catalog-pack-01-20261015`, AMD64, собран поверх точного
  предыдущего API image `avtorinok-api:dealer-analytics-20261014-4400788`.
- Web image: `avtorinok-web:catalog-pack-01-20261015`, AMD64. Сборка взята из
  активного серверного `site-assistant-20261014-r3`, изменён только sell-form.
- В существующих release-каталогах обновлены соответствующие исходные файлы
  и image overrides. Активный symlink не переключался. API пересоздан своим
  исходным Compose-проектом; web — своим. Worker, DB, SMTP не пересоздавались.
- Значения environment и отсортированные mounts API/web/worker совпали до/после.
  `.env` остаётся 600. Nginx и режим доступа не изменялись. Миграций не было.

## Резервирование и откат

До записи сделан полный `pg_dump -Fc`:
`/home/suite/apps/catalog-pack-01-20261015/backup/pre-import.dump`.
SHA-256 проверен; `pg_restore --list` успешно прочитал дамп.

Файлы исходников и Compose до активации сохранены; точное сопоставление:
`backup/activation-files.json` в серверном рабочем каталоге. Для отката приложения
восстановить указанные файлы и выполнить `docker compose up -d --no-deps
--no-build --wait api` из сохранённого рабочего каталога API и аналогично `web`
из его каталога. Данные при таком откате остаются в БД. Полное восстановление
БД из дампа требует отдельной оценки новых записей после импорта и не выполнялось.
Не использовать `down -v`.

## Свежие проверки

- Dry run: 17 новых марок, 3 переиспользованных, 718 новых моделей.
- Apply: те же количества, успешный commit.
- Повторный dry run: все 20 марок и 718 моделей переиспользованы,
  `models_metadata_updated=0`; новых строк нет.
- Проверка нового FastAPI router настоящим HTTP через временный loopback Uvicorn
  в API-контейнере: 10 марок/380 моделей мото, 10/338 грузовых; легковые — прежние
  94 марки; автобусы остаются без импортированного каталога.
- Web production build и встроенная проверка TypeScript прошли.
- После активации внешний HTTPS со стороны клиентского компьютера проверил
  все 718 моделей через публичный API по каждой марке и категории, а также
  HTTP 200 главной, `/trucks`, `/motorcycles`, `/login?next=%2Fsell`.
- Все пять сервисов healthy. Проверены сохранность environment/mounts и ID worker.
- В реальном браузере `/trucks` загрузился и показывает отсутствие опубликованных
  предложений, что соответствует импорту справочников, а не объявлений.
- Browser-проверка `/sell?category=motorcycles` упёрлась в штатный вход:
  активной сессии пользователя нет. Подсказки внутри авторизованной формы
  в браузере не проверены. Аккаунты и объявления для проверки не создавались.

Примечание: сервер не смог обратиться к собственному внешнему HTTPS (connection
refused); финальный внешний smoke успешно выполнен с клиентского компьютера.
Первичная попытка TestClient недоступна из-за отсутствия httpx2 в production;
вместо установки зависимостей использован настоящий временный HTTP-сервер.
