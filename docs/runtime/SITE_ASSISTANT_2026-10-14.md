# Помощник Авторынка — 14 октября 2026

## Реализация

Виджет в нижнем углу, оригинальный маскот, поиск по параметрам с сохранением условий диалога и уточнением валюты. До четырёх актуальных публичных объявлений с фото/ценой/характеристиками, ссылка на полную подборку, явные ошибки и пустая выдача. Сравнение первых трёх повторно читает публичные карточки и выводит факты без придумывания состояния автомобиля. Справочные ответы со ссылками, пересказ публичной страницы, браузерная озвучка/голосовой ввод при поддержке.

OpenRouter подключён по прямому запросу пользователя. Модель `dots-studio/dots-3-note-preview:free`, только `:free`, `data_collection=deny`, без платных fallback. Серверные лимиты и размеры описаны в ASSISTANT_OPENROUTER.md. Проверка ключа после вызовов: usage=0. Значение ключа в отчёт и Git не включено. Пользователь передал ключ в чате; рекомендована последующая ротация через скрытый ввод.

- 13 целевых тестов: парсинг/валюта/контекст, валидация, приватные страницы, endpoint origin/размер тела, бесплатные модели, фактическое сравнение.
