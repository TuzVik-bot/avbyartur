## Изменения
- Постоянная прямая кнопка кабинета в мобильной шапке; гостю — вход с возвратом в кабинет.
- «Предложить обмен» для активного объявления с обменом, кроме собственного. Намерение сохраняется через вход; текст сообщения редактируется и автоматически не отправляется. На сервере страницы доступность обмена проверяется повторно.
- Комплектация: понятные названия известных опций, расшифровка ABS/ESP. Импорт Onlíner содержит идентификаторы полей без значений, поэтому не считается подтверждением наличия оборудования. Неизвестные коды не выводятся, вместо них предложение уточнить комплектацию.
- Гостевой просмотр контактов включён. Сообщение 429 локализовано. Добавлен `GUEST_CONTACT_IP_HOURLY_LIMIT`: безопасный прежний default 30, на текущем общем web-прокси — 300/час. Ограничения устройства (30/час), объявления (300/час), cookie/header proof и CSRF для вошедших сохранены.
- Включён `LISTING_AUTO_PUBLISH_ENABLED=true`: новые отправки публикуются после всех существующих проверок, включая фото, заполнение, владельца, компанию и квоту. Сохраняются ревизии, история статусов, аудит `auto_published`, уведомления и история цены. Старые pending_review массово не менялись.
- Финальная кнопка размещения — «Разместить объявление».
- Фильтр марки на действующем сайте уже работал: подтверждено 889 -> 16 для Volvo. Его реализация сохранена; проверены марка и марка+модель после отправки формы.

## Практические ограничения
Общий лимит прокси 300/час всё ещё объединяет гостей; повышение устраняет слишком низкий порог, но не создаёт раздельные IP. При превышении остаётся корректная 429. Для независимых IP понадобится отдельная настройка доверенной цепочки прокси.
Production-объявление и production-аккаунт для проверки не создавались. Публикация целиком проверена в одноразовой БД, на сервере проверен включённый флаг.
Локальная рабочая папка имеет другие, более старые и несвязанные изменения; не утверждается её полное совпадение с релизом. Для следующего релиза использовать production baseline и приложенный delta.
