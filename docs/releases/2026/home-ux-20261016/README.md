# UX-переделка главной — 16 октября 2026

## Цель и scope

Плотная, ровная главная автомобильного портала: быстро перейти от поиска к объявлениям и подаче. Применены `product-design:audit`, `redesign-existing-projects`; сохранены существующие Next.js/CSS Modules, бело-синяя палитра и переменные тем.

## Аудит текущей страницы

1. `01-before-search.png`: первый блок на desktop 1280 px занимал 796 px. Пустое рекламное место сужало поиск; кнопка начиналась со второй колонки. Второй рекламный блок добавлял длину до объявлений.
2. Марки дублировались вверху и внизу; категории занимали отдельные 337 px. В разных секциях использовались разные интервалы.
3. `02-before-seller.png`: самостоятельные крупные секции продавца, шагов, компаний и калькулятора растягивали низ; одна фотография повторялась дважды.
4. В новой мобильной композиции обнаружен конфликт старого global CSS: `.home-search .search-range` принудительно занимал две колонки. Переопределение теперь находится в scoped CSS страницы.

Сильные стороны сохранены: реальный поиск, категории из общего справочника маршрутов, честные состояния ошибок и пустого каталога, существующие вход/подача и доступ к полной выдаче.

## Изменения

- Поиск на всю ширину, пять колонок desktop, три tablet, две mobile. Диапазоны и кнопка выровнены без пустой колонки.
- Единственный список марок, все 13 категорий, компактная полоса реальной статистики. Полное объяснение модерации доступно через native details.
- Восемь новых объявлений: четыре колонки desktop, три tablet, две промежуточные, одна на телефоне. До 520 px показаны первые четыре карточки и кнопка «Смотреть все объявления».
- Блок подачи и три шага объединены. Одна иллюстрация ограничена по высоте.
- Четыре полезных сервиса и компании собраны в общий ряд. Вместо двух пустых рекламных заглушек — компактное предложение сотрудничества с рабочей ссылкой.
- Сохранены заметный keyboard focus, подписи форм, семантические заголовки, реальные ссылки и описания недоступной VIN-интеграции без обещания работающей проверки.

## Проверки

- 15 тестов главной/поиска PASS. TypeScript PASS.
- Локальная production-сборка `next build --webpack` PASS. Turbopack в изолированной tmp-копии не принимает внешний symlink node_modules; это ограничение локального стенда, не ошибка исходника. Серверная Docker/Turbopack-сборка нового релиза PASS.
- Браузер: 1280, 768, 390, 320 px; горизонтального переполнения нет. Светлая/тёмная темы проверены. Мобильный поиск после устранения конфликта global CSS проверен повторно.
- Для заполненной сетки использован отдельный локальный HTTP fixture-сервер на 3019 и preview на 3018. Карточки помечены `[Локальный макет]`; никакие fixture-данные на VPS не отправлялись. `04-local-fixtures-grid.png` показывает ровные четыре колонки, две строки; `05-preview-mobile-dark.png` — мобильный поиск.

- `03-preview-search.png` и `06-preview-seller.png` — итоговая композиция. У всех 8 локальных карточек одинаковая ширина и выровненные строки; на телефоне видны 4 карточки.
