## Фактическое состояние

- SSH через `fortebit-prod` успешно аутентифицирован как `suite`. Активный релиз: `pilot-20261002T133421Z`.
- API, web, worker и PostgreSQL здоровы. Web опубликован на loopback `127.0.0.1:8080`; данные и тома не изменялись.
- Общий пароль Nginx пока включён: главная, каталог и API снаружи возвращают HTTP 401 с Basic Auth. Подготовленная правка требует sudo. Временная локальная форма: http://127.0.0.1:18741 . Пароль не передаётся в чат и не записывается в файлы.
- Внутри VPS главная, `/cars`, `/dealers`, `/login`, `/sell` и `/account` отвечают HTTP 200. Это проверка доступности страниц, а не успешной подачи объявления или модерации. `/api/v1/me` без сессии отвечает 401: кабинет остаётся защищённым.
- API объявлений работает, опубликованных записей — **0**. Синтетические объявления на VPS не добавлялись.
- Калькулятор и его API на VPS отвечают **404**. Он реализован и проверен локально, но ещё не опубликован на сервере.
- По runtime-флагам отключены SMS-вход, SMS-регистрация, email-уведомления, подтверждение email и восстановление пароля.
- Просмотр контактов гостем отключён. Список тарифов пуст. Реальные платежи и внешняя доставка сообщений не выполнялись.

## Сценарии для пользователей

| Сценарий | Что проверить | Условие или ограничение |
|---|---|---|
| Гость | Главная, фильтры, компании, документы, мобильная версия | Сначала снять общий пароль; каталог пока пуст |
| Продавец | Обычный вход, черновик, характеристики, фото, подача | Нужна действующая учётная запись; SMS-регистрация отключена |
| Модератор | Очередь, проверка, публикация и отклонение | Нужна роль модератора и реальное поданное объявление |
| Покупатель | Поиск, карточка, избранное, контакты | Сначала опубликовать реальное объявление; контакты требуют входа |
| Переписка | Диалог, сообщения, прочтение, блокировка | Нужны учётные записи и опубликованное объявление |
| Калькулятор | Исходные данные, курсы, раздельные платежи | Требуется релиз калькулятора на VPS |
| SMS/email | Доставка, подтверждение, восстановление | Возможности сейчас отключены |
| Продвижение/оплата | Тариф, заказ, результат платежа | Тарифов нет; платежи не проверены |

## Как фиксировать ошибки

Для каждого случая: роль, адрес страницы, время по Минску, шаги, ожидаемый и фактический результат, скриншот без паролей и личных данных.

Общий HTTP Basic Auth и обычный вход в кабинет — разные уровни доступа. Пользователь попросил убрать первый; авторизация и роли приложения сохраняются.

## Границы проверки

HTTP 200 не подтверждает работу всех функций. Подача, фото, модерация, переписка, внешняя доставка, платежи и новый калькулятор на VPS в этой проверке не пройдены. Для снятия общего пароля подготовлены резервная копия конфигурации, `nginx -t` и откат; применение ожидает sudo-аутентификации. Production-данные, ENV, тома, сервисы и настройки индексации не менялись.
