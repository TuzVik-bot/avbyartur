# Лично наблюденные контрольные расчеты ГТК — 2026-10-04

Проверил: основной агент `/root` в текущей задаче Codex. Метод: `mcp__cua_repl` в браузере Codex, официальный https://customs.gov.by/calc/, раздел «Легковые автомобили для личного пользования». Это отчет о выполненных взаимодействиях, а не ожидаемые суммы из нашего кода. Текст результата прочитан из UI после каждого клика «Рассчитать». Инструментальные output и скрин первого примера находятся в текущей истории задачи. Предыдущая неподтвержденная сводка агента не использована как доказательство.

## Метод воспроизведения
1. Выбрать легковые автомобили и указанную возрастную группу.
2. Ввести цену EUR (только для <=3 лет), объем см³ и вручную заданный контрольный курс EUR/BYN. Для групп >3 цена в интерфейсе отсутствует.
3. Кликнуть «Рассчитать»; прочитать обе отображаемые суммы EUR и BYN.
4. «Рассчитать другой автомобиль» для следующего случая. Ввод с обычными клавиатурными событиями: простой DOM fill не активирует старую jQuery-валидацию.

Курс 3/3.5 — контрольный пользовательский ввод для сверки, а не текущий курс НБРБ. Проверка возраста через точную дату в GTK недоступна: форма принимает группу. Проверка таможенного сбора и утиля выполняется отдельно по нормам. Наше ядро сравнивается по EUR и по BYN при том же контрольном курсе. GTK выводит float-хвосты: сохраняем raw, для сравнения до копеек применяется Decimal HALF_UP. Decimal цену +0.01 в GTK не проверяли; шестой ценовой диапазон представлен ценой169001.
