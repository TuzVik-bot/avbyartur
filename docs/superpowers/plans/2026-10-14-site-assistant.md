# Помощник Авторынка

Цель: чат в нижнем углу с поиском реальных объявлений, ответами со ссылками на страницы сайта и голосовым пересказом публичной страницы. Пользователь одобрил реализацию, push и deploy 14 октября 2026.

Архитектура: клиентский виджет и отдельный Next.js server route; существующий публичный API каталога остаётся источником данных. Условия поиска передаются между сообщениями. Валюта уточняется до поиска по цене. ИИ-провайдер настраивается только на сервере; при отсутствии ключа доступен явно обозначенный базовый поиск. Приватные страницы и поля форм не пересказываются и не отправляются модели. Озвучивание через speechSynthesis; распознавание речи только по явному действию и при поддержке браузером.

Ограничения: не добавлять объявления, не менять API/БД/worker, не выводить секреты; фиксированные публичные источники, проверка входных параметров и лимиты запросов. Отдельный web-релиз на копии актуального VPS-кода с сохранением rollback, .env и томов.
