# Ownership Calculator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax for tracking.

**Goal:** Калькулятор владения для Беларуси с запуском из объявления и сравнением двух машин.

**Architecture:** Чистое математическое ядро TypeScript, клиентская форма с CSS module, серверная страница с адаптером публичных объявлений. Независимые файлы распределены между тремя агентами GPT-6 Luna.

**Tech Stack:** Существующие Next.js, React, TypeScript, Vitest; без новых зависимостей.

**Spec:** `docs/superpowers/specs/2026-10-26-ownership-calculator-design.md`

## Global Constraints

- Существующие изменения других задач сохраняются.
- Без новых зависимостей, backend-изменений, миграций, production-действий и публикации.
- Собственный CSS module использует текущие цветовые и тематические токены.
- Налог, страховка и техосмотр вводятся пользователем; нулевые суммы явно отмечаются как не включенные.
- Стоимость владения не включает повторно тело кредита; ежемесячный бюджет включает полный платеж.
