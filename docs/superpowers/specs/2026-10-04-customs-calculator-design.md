# Таможенный калькулятор — дизайн первой версии

Дата: 2026-10-04. Пользователь поручил подготовить план и запустить разработку на GPT-6 Luna max; дополнительное согласование начала не требуется.

## Сценарий и продукт
Физическое лицо ввозит для личного пользования легковой автомобиль категории M1 с бензиновым или дизельным ДВС из-за пределов ЕАЭС в Беларусь без льгот. EV, любые гибриды, ввоз из ЕАЭС, юрлица и льготы исключены явно. Цена покупки является оценкой таможенной стоимости; окончательную стоимость определяет таможня. Доставка, брокер, страхование и покупная цена не входят в итог таможенных платежей. Не добавлять фиктивные строки расходов.

Страница `/customs-calculator`, название «Таможенный калькулятор», ссылки в шапке и разделе «Разделы» подвала. Стиль текущего сайта: светлый фон, синий акцент. Форма: цена, EUR/USD/BYN/RUB/CNY, точная дата выпуска, бензин/дизель, точный объем см³, подтверждение личного пользования и ввоза вне ЕАЭС. Год без точной даты не подменяет дату выпуска. Все поля доступны ручному редактированию. Каталог пока не дает достоверной точной даты: автоматический выбор модели не нужен первой версии.

## Расчет и источники
Серверный Python Decimal без float для денег и порогов. ЕЭК №107 приложение 2: <=3 года — максимум процента цены в EUR и минимальной ставки EUR/см³; >3 <=5 и >5 — объемная ставка. Возраст по календарным годовщинам, отдельно тестировать 29 февраля. Пороги цены сравнивать до округления. Округление денежных строк до копеек HALF_UP, итог равен сумме отображаемых строк.

Раздельно показывать единую пошлину/налоги, утильсбор, обязательный сбор за операции и итог этих платежей BYN. Не добавлять НДС отдельно поверх единой ставки. Юридические таблицы — JSON в `backend/app/data/customs-rules.json`, с id, effective_from, effective_to (exclusive или null), source URLs, verified_on и статусом сверки. Точные ставки и даты действия принимает исследование `docs/customs/RULES_RESEARCH_2026-10-04.md`, опубликованный первичный источник обязателен для каждого тарифа. Ставки утиля из №195 с 2026-04-29; прежние значения не восстанавливать по памяти. Нет подходящей версии — явная ошибка, не последняя известная ставка.

Курсы — `https://api.nbrb.by/exrates/rates?periodicity=0&ondate=YYYY-MM-DD` (официальный API НБРБ). Единый снимок на текущую дату Europe/Minsk, Cur_OfficialRate / Cur_Scale. Проверять дату, валюту, конечное положительное число, целую положительную кратность. EUR нужен всегда. Для BYN курс 1. Не использовать USD курс из marketplace worker, он не содержит EUR и не гарантирует одну дату. Кэш только успешного снимка на эту дату, ограниченный размер/TTL и защита от одновременных загрузок. При недоступности, неверном ответе или старой дате — 503 без выдуманного/устаревшего пересчета. Жесткий hostname, таймаут, ограничение размера ответа; никаких URL от пользователя.

## Контроль перед показом сумм
Суммы обычным пользователям доступны только после сверки контрольных примеров с официальным ГТК: младше/ровно 3/>3/ровно 5/>5 лет, каждый диапазон цены и объема, процент/минимум. Исследователь сохраняет реальный статус и доказательства в `docs/customs/gtk-control-cases.json`. Если онлайн-калькулятор недоступен, автоматические нормативные тесты остаются локальной проверкой, а метаданные явно показывают `calculation_available=false` и POST отвечает `customs_rules_unverified`, без сумм. Нельзя включить публичный расчет одним флагом ENV; статус выпуска привязан к версии правил и проверенным контрольным примерам. Локальные unit-тесты напрямую проверяют математическое ядро без обхода публичного барьера.

## API
`GET /api/v1/customs-calculator/meta`: scenario, supported_currencies, supported_engines, calculation_available, unavailable_reason, rules_version, verified_on, sources, scope_notes. `POST /api/v1/customs-calculator/calculate`: price_amount decimal string, currency, manufacture_date ISO, engine_type petrol/diesel, engine_volume_cc integer, personal_use=true, origin_outside_eaeu=true. Дату расчета задает сервер. Результат: calculation_date, rules_version, age_band, customs_value_eur, duty_eur, duty_byn, recycling_fee_byn, customs_fee_byn, total_byn, rate_date, rates_used (currency, official_rate, scale, byn_per_unit), sources, warnings. Типы через OpenAPI generator. Ошибки ApiErrorOut проекта: 422 валидация/сценарий, 503 курсы/нет правил/нет сверки. Публичный read-only расчет не меняет БД и не требует аккаунта. Публичный POST не сохраняет данные и не требует CSRF/idempotency.

## Проверки и границы
Тесты ядра и API без БД, сетевые ответы замоканы только для транспортных ошибок. Никаких fixture integration без выделенной одноразовой БД. Проверка формы Vitest на реальное поведение: ввод, отправка, серверный результат, недоступность, ошибки, скрытие старого результата после изменения ввода, защита от позднего ответа. Typecheck и build. Браузер: desktop/mobile, доступность, отсутствие overflow, реальный локальный API и курс НБРБ; если барьер сверки закрыт, проверить честное сообщение и отсутствие сумм. Сохранять noindex/Basic Auth и production данные. VPS/deploy/миграции/импорт не входят в задачу.
