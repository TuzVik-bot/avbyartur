# Демоданные финансовой заявки

> Только для локальной разработки и тестов. Не является заявкой реального лица, действительным согласием на обработку персональных данных, публичной политикой или юридическим заключением. Не загружать на VPS и не включать приём реальных заявок.

## Синтетическая запись

```json
{
  "fixture_id": "DEMO_ONLY_FINANCING_0001",
  "environment": "local_test_only",
  "application_status": "new",
  "applicant": {
    "name": "DEMO_ONLY_PERSON_0001",
    "contact_method": "email",
    "contact": "financing-demo@example.invalid",
    "applicant_type": "individual"
  },
  "vehicle": {
    "listing_id": null,
    "category": "trucks",
    "label": "DEMO_ONLY: условный грузовой автомобиль",
    "price": 50000,
    "currency": "BYN"
  },
  "financing": {
    "product_type": "leasing",
    "budget": 50000,
    "down_payment": 10000,
    "term_months": 36,
    "rate_percent": null,
    "residual_payment": null
  },
  "consent": {
    "given": false,
    "purpose": null,
    "operator": null,
    "partner_transfer": false
  },
  "production_submission_enabled": false

```

`example.invalid` — зарезервированное доменное имя для примеров. Номер телефона, паспортные данные, идентификационный номер, карта, банковские коды и сведения о реальном кредиторе не используются. Суммы и срок придуманы исключительно для проверки интерфейса; это не условия финансирования или предложение банка/лизинговой компании. Ни одно поле из этой фикстуры не должно отправляться по сети или попадать в production БД.

## Сведения, без которых нельзя включать реальный сбор

Заполнить и проверить с ответственным за обработку и юристом до разработки активной формы. Пустые значения нельзя заменять вымышленными реквизитами.

| Поле/решение | Значение для настоящего сценария |
|---|---|
| Оператор: полное наименование или ФИО, адрес места нахождения/жительства | `ТРЕБУЮТСЯ ФАКТИЧЕСКИЕ ДАННЫЕ` |
| Цель обработки и правовое основание | `УТВЕРДИТЬ ДЛЯ КОНКРЕТНОГО СЦЕНАРИЯ` |
| Категории собираемых данных и минимальный состав | `УТВЕРДИТЬ; НЕ СОБИРАТЬ ПАСПОРТ/БАНКОВСКИЕ ДАННЫЕ БЕЗ НЕОБХОДИМОСТИ` |
| Срок действия согласия и критерий/срок хранения заявки | `ОПРЕДЕЛИТЬ ПО ЦЕЛИ И ОБЯЗАТЕЛЬНЫМ СРОКАМ` |
| Уполномоченные лица, фактические получатели и страны передачи | `УКАЗАТЬ КАЖДОГО ДО ПЕРЕДАЧИ` |
| Операции и способы обработки, меры защиты | `ОПИСАТЬ ПО ФАКТИЧЕСКОЙ СИСТЕМЕ` |
| Права человека, порядок обращений/отзыва согласия | `УКАЗАТЬ РЕАЛЬНЫЙ КАНАЛ И ПОРЯДОК` |
| Последствия согласия и отказа | `ОПИСАТЬ БЕЗ ЛИШЕНИЯ ДОСТУПА К НЕСВЯЗАННЫМ ФУНКЦИЯМ` |
| Передача банку/лизинговой компании | `ВЫКЛЮЧЕНА; включать только для конкретного названного получателя и основания` |
| Ответственный сотрудник, доступ к очереди и срок доступа | `НАЗНАЧИТЬ ФАКТИЧЕСКИ; ограничить круг доступа` |

## Перед production

Закон Республики Беларусь № 99-З предусматривает свободное, однозначное и информированное волеизъявление, а оператор до получения согласия предоставляет сведения о себе, целях, данных, сроке, уполномоченных лицах и действиях/способах обработки и понятно разъясняет права, механизм их реализации и последствия согласия или отказа. Хранение ограничивается необходимостью для заявленной цели; трансграничная передача оценивается отдельно. Точные требования нужно сверить с актуальным официальным текстом закона и НЦЗПД для конкретного потока данных.

Пока фактические сведения не утверждены:

- не создавать публичную форму заявки и чекбокс согласия;
- не собирать реальные контакты, не сохранять реальные обращения и не передавать их финансовым партнёрам;
- не обозначать этот файл или `/credit-policy` как утверждённое согласие;
- держать работающим только локальный расчёт параметров, введённых самим пользователем; значения калькулятора не отправляются на сервер.

Официальные справочные материалы: [НЦЗПД — Закон № 99-З (английский перевод помечен как неофициальный)](https://cpd.by/en/national-regulation/the-belarusian-data-protection-act/) и [НЦЗПД — трансграничная передача](https://cpd.by/be/abarona-persanalnyh-danyh/aperataru/transgranichnaja-peradacha/). Этот пример помогает проверить структуру разработки, но не заменяет юридическую экспертизу.
