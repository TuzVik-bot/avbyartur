# Generated interface images

Nine original ImageGen PNGs are kept in `originals/`; optimized, project-sized WebP files are used by the portal. `manifest.json` records dimensions, byte budgets, alternative text, and intended placement.

All images are decorative illustrations generated for this redesign. They do not represent actual listings, dealerships, customers, testimonials, or commercial guarantees. Never use these assets as listing photos or photo fallbacks. Listing media must come from the listing; use a neutral no-photo state otherwise.

A separate portrait composition is provided for the mobile hero. Text is rendered as HTML, never baked into the image. Preserve the cornflower/neutral palette and check subject placement when changing aspect ratios.
